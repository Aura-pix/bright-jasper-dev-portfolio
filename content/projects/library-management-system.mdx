## What it is

A library management system built with my project group and presented to lecturers and students. It runs on PHP and MySQL through XAMPP. As the group leader, i organized the project, scheduled meetings so everyone understands what's built, delegated tasks to each member and also reviewd the code to ensure it meets the requirements. The presentation was quite a success

## Task

An end to end project featuring authentication, CRUD operations, database configuration using MySQLi, SQL injection prevention (using prepared statements), and form validations. To be run locally during presentation. Used to assess course work about CRUD operations, backend web develpment and security best practices.

## Stack

PHP, MySQL and XAMPP.

## Extras

To deepen my understanding of PHP as opposed to my main stack (Javascript), i hosted the project online using docker to deploy to Render. It was an interesting experience as i learnt PHP wouldn't deploy to Vercel or Netlify the way i'd deploy a regular Next.js app seamlessly. It required a few tweaks to the configuration and using DBeaver to manage the database but it was worth it
